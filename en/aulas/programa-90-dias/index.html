Lesson 8 · 20 min

The 90-day program and what changed

The seven lessons become a program: in 90 days, one to three managers take one tool each from the map to the handoff to IT, with fixed meetings and milestones you can check. At the end, the final project at Horizonte and the dashboard of what changed in the market this quarter.

02 · How to set up and run the program

Click each step.

1. Roles before dates

Sponsor: the owner (Carlos) opens doors and decides at the end. Managers: build and own the processes. IT: validates and takes over. Mentor: leads the method and the pace.

Also choose one reference user per tool, who will use it every day and say whether it feels comfortable.

At HorizontePatrícia (follow-up), Juliana (ready-made customer service replies), and Rafael in IT.

2. Fixed rhythm

One 60-minute weekly meeting per manager, always on the same day. Plus the long prototyping and acceptance testing sessions on the right dates.

Between meetings, the manager has a task with a "done when". Without a task, the program turns into conversation.

RuleA missed milestone changes the date of the next one, never the criterion.

3. Verifiable milestones

Each phase closes with something anyone can check: the map table, the prototype opening, the test suite with a score, the IT decision, the dashboard with a baseline.

On day 90, a meeting with the owner: what changed in the numbers, what it costs, what comes in the next cycle.

Day 90 question"Do we continue, expand, or stop? Based on what?"

4. Final project

Build the 90-day plan for Horizonte for Patrícia and Juliana, and deliver the eight completed templates for the follow-up tool.

Use the lab pieces to show what the program prevents: each failure F1 to F12 must appear in some control in your plan.

05 · What changed (Oct/2026)

Dashboard updated every quarter. The tool changes; the method from lessons 1 to 7 stays.

A work agent for everyoneOct/2026: OpenAI brought GPT-6 to everyone in ChatGPT, on free and paid plans. The manager can prototype without a new license; the care with real data stays the same. OpenAI, Deployment Safety Hub
An agent that uses the computerSep/2026: Claude Code started using the computer in the background in the desktop app (beta, Pro and Max plans). More power calls for more limits: per-action permissions matter even more. Claude Code, week 36 news
Cost per task falling09/22/2026: Anthropic launched Opus 5.5, which it says costs 40% less than Opus 5 on typical tasks. Run the test suite with the new model before switching. Anthropic
A tool being retiredAnnounced on 06/03/2026: OpenAI's Agent Builder goes offline on 11/30/2026. That is why the handoff package keeps rules, code, and access outside the tool. OpenAI, deprecations
Security scanning in the coding agent2026: the Codex documentation now includes repository security scanning. It helps Rafael, but it does not replace the IT review or the penetration test. Codex changelog
A harder entry into a career08/12/2026: Stanford estimates that employment for ages 22 to 25 in the occupations most exposed to AI is 19% lower than it would have been had it tracked that of peers in less exposed occupations; the study does not claim a cause. Mentoring and programs like this one gain weight. Stanford Digital Economy Lab
